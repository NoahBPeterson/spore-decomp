# Help wanted: make equivalent functions byte-exact

Every function listed here already has complete C++ source that compiles and behaves like the original (checked by differential tests), but the compiled bytes still differ from `SporeApp.exe`. Closing that gap means finding the source shape the original compiler (MSVC 9.0) was given: declaration order, types, temporaries, inlining, loop form. No new reverse engineering is needed to start.

## How to work on one

1. Set up the repository as in the [README](../README.md); you need your own copy of the game, from which the tools derive their local analysis files. The repository contains no game code or data.
2. Read [docs/matching.md](matching.md): how functions are compiled, compared and recorded.
3. Pick a function below. `source` is the file that defines it, at the `// @ 0x<va>` marker.
4. Compare your build with the original: `.venv/bin/python tools/matching/chk.py <source> <va>`, and `tools/matching/cmpdis.py` for an instruction-level diff (usage in docs/matching.md).
5. When it matches, move its row from `nonmatching.txt` to `manifest.txt` and open a pull request; `tools/matching/run_all.py --manifest <dir>/manifest.txt` must print every row MATCH.

Never change what a function does to make bytes match, and never paste in assembly: the source has to be plain C++ that compiles to the original.
